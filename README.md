# Arafat Raboudi: portfolio

Static one-page portfolio for GitHub Pages. No build step.

## Files
- `index.html`: the whole page (HTML, CSS and a small script)
- `assets/img/`: portrait, banner and gallery photos (WebP)
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Publish
1. Create a repository named `YOURUSERNAME.github.io` and upload everything in this folder to its root.
2. Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
3. Open `https://YOURUSERNAME.github.io` after a few minutes.

## Edit
Open `index.html` in any editor. Replace a photo by uploading a new file with the same name in `assets/img/`.
